# 👾 Alien Hunter - C++ Console Game

Welcome to **Alien Hunter**, a simple yet addictive console-based shooter game written entirely in **C++**. Your mission? Shoot down the aliens before they crash into your spaceship! 🚀

---

## 🎮 Game Preview

🛸 A spaceship.  
👾 Incoming aliens.  
💥 Bullets.  
🏆 Score system.  
📈 High-score tracking.

All inside your terminal window!

---

## 📋 Features

- Classic arcade-style alien shooter.
- Real-time keyboard controls.
- Bullets and spaceship movement.
- Alien generation and animation.
- Score and high-score system.
- Persistent high score (stored in a file).
- Console-based interface with custom border drawing.

---

## 🧠 Controls

| Key       | Action              |
|-----------|---------------------|
| `←`       | Move left           |
| `→`       | Move right          |
| `SPACE`   | Fire bullets        |
| `ESC`     | Exit the game       |

---

## 🛠️ Requirements

- **Operating System**: Windows (required for `<windows.h>`, `Beep()`, `SetConsoleCursorPosition`, etc.)
- **Compiler**: Any standard C++ compiler (e.g., g++, Visual Studio)
- **Terminal**: Command Prompt or any terminal that supports Windows API

---

## 🧾 How to Run

1. Clone or download the repository.
2. Open the project in your preferred C++ IDE or text editor.
3. Compile using a C++ compiler:

   ```bash
   g++ -o AlienHunter AlienHunter.cpp
